# HRC — Haneul Racing Championship

**▶ 플레이: https://ksa32-14th.github.io/HanuelAcademy_Gaming_Server_Racing/**

브라우저에서 바로 돌아가는 F1 스타일 레이싱 게임입니다. 설치도, 빌드도 필요 없습니다.
`index.html` 한 파일에 게임 전체(물리·AI·3D 렌더링·HUD)가 들어 있고, Three.js만 CDN에서 불러옵니다.

## 수정하기

고칠 곳은 `index.html` 하나뿐입니다. GitHub 웹에서 연필 아이콘을 눌러 고치고 커밋하거나,
`git push`로 올리면 **1~2분 뒤 위 주소에 자동 반영**됩니다. 따로 빌드하거나 배포할 것이 없습니다.

반영이 안 된 것처럼 보이면 브라우저 새로고침(`Ctrl+F5`)을 해 보세요.

로컬에서 확인할 때는 `index.html`을 브라우저로 그냥 열면 됩니다.

## 조작

| 키 | 기능 |
| --- | --- |
| `W` | 가속 |
| `A` / `D` | 조향 |
| `SPACE` | 브레이크 |
| `E` | DRS 개방 |

| `P` | 일시정지 |

| `M` | 사운드 |

## 게임 내용

- **차량 물리** — 다운포스, 타이어 그립(속도에 따라 변함), 마모, 연료 무게, 슬립 앵글(언더스티어·오버스티어), 슬립스트림. 최고 속도는 출력과 공기 저항이 균형을 이루는 지점에서 자연스럽게 정해집니다(약 330 km/h, DRS 시 더 높음).
- **레이싱 라인** — 트랙 폭 안에서 곡률이 가장 작은 경로를 직접 계산합니다. 아웃-인-아웃이 규칙이 아니라 계산 결과로 나옵니다.
- **AI** — 19대가 이 라인과 속도 프로파일을 따라 달리며, 추월·방어·피트 전략을 스스로 판단합니다.
- **레이스 규정** — 2022 규정 기반. DRS(3초 이내 감지), 피트 60 km/h 리미터, 2종 컴파운드 의무 사용, 트랙 리밋 페널티.
- **송도 서킷** — OpenStreetMap의 실제 건물 외곽선과 높이를 그대로 씁니다. 포스코타워, G타워, 컨벤시아, 트리플스트리트, 센트럴파크 등이 실제 위치에 서 있습니다.
- **다시보기** — 모든 차량의 직전 20초를 기록해 트랙 옆 중계 카메라로 재생합니다.

## 기술

Three.js r160 (ES 모듈, CDN), WebGL2, EffectComposer 블룸. 빌드 도구도, 설치할 의존성도 없습니다.
