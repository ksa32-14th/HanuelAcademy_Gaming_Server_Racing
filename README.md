# HRC — Haneul Racing Championship

브라우저에서 바로 돌아가는 F1 스타일 레이싱 게임입니다. 설치할 것도, 빌드할 것도 없습니다.
`index.html` 하나에 게임 전체(물리·AI·3D 렌더링·HUD)가 들어 있고, Three.js만 CDN에서 불러옵니다.

## 플레이 방법

`index.html`을 브라우저로 열면 됩니다. GitHub Pages를 켜면 그대로 웹에서 플레이할 수 있습니다.

로컬에서 돌릴 때는 파일을 직접 열어도 되고, 간단한 서버를 써도 됩니다.

```bash
python -m http.server 8000
```

| 서킷 | 길이 | 랩 | 설명 |

## 게임 내용

- **차량 물리** — 다운포스, 타이어 그립(속도에 따라 변함), 마모, 연료 무게, 슬립 앵글(언더스티어·오버스티어), 슬립스트림. 최고 속도는 출력과 공기 저항이 균형을 이루는 지점에서 자연스럽게 정해집니다(약 330 km/h, DRS 시 더 높음).
- **레이싱 라인** — 트랙 폭 안에서 곡률이 가장 작은 경로를 직접 계산합니다. 아웃-인-아웃이 규칙이 아니라 계산 결과로 나옵니다.
- **AI** — 19대가 이 라인과 속도 프로파일을 따라 달리며, 추월·방어·피트 전략을 스스로 판단합니다.
- **레이스 규정** — 2022 규정 기반. DRS(3초 이내 감지), 피트 60 km/h 리미터, 2종 컴파운드 의무 사용, 트랙 리밋 페널티, 세이프티 관련 플래그.
- **송도 서킷** — OpenStreetMap의 실제 건물 외곽선과 높이를 그대로 씁니다. 포스코타워, G타워, 컨벤시아, 트리플스트리트, 센트럴파크 등이 실제 위치에 서 있습니다.
- **다시보기** — 모든 차량의 직전 20초를 기록해 트랙 옆 중계 카메라로 다시 보여줍니다.

## 저장소 구조

```
index.html          플레이용 페이지 (빌드 결과물, 커밋에 포함)
src/hrc-game.html   게임 소스. 여기를 수정합니다
tools/build.sh      src → index.html 생성
```

소스를 고친 뒤에는 `bash tools/build.sh`를 돌려 `index.html`을 다시 만들고 함께 커밋하세요.
`src/hrc-game.html`은 `<!doctype>`/`<html>` 태그가 없는 조각 파일이라 그대로 열면 안 됩니다.

## 기술

Three.js r160 (ES 모듈, CDN), WebGL2, EffectComposer 블룸. 빌드 도구·의존성 설치 없음.
